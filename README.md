# Galerry foto dilraba
Multi-page photography/gallery website built with HTML, Tailwind CSS CDN, and vanilla JavaScript.

Pages:
- index.html
- gallery.html
- portraits.html
- editorial.html
- collections.html
- about.html
- contact.html

Shared assets:
- assets/css/style.css
- assets/js/app.js

Notes:
- Demo images use picsum.photos.
- Tailwind CSS and Google Fonts load from CDN.
- Contact form is front-end only; connect it to your backend/email service for production.
